# Bench Test Checklist

- [ ] Wheels lifted or motor outputs disconnected for first power-up.
- [ ] Polarity and continuity checked before applying power.
- [ ] Logic and motor supply requirements checked against datasheets.
- [ ] Trigger/echo pins filled in from actual wiring.
- [ ] Echo voltage compatibility checked.
- [ ] LCD adapter implemented using supplied library API.
- [ ] Motor adapter implemented using verified Firebird V functions.
- [ ] Sensor timeout behavior checked before enabling movement.
- [ ] Threshold tested with a target at a safe distance.
- [ ] Manual power cutoff is accessible.
- [ ] Test results recorded honestly.
